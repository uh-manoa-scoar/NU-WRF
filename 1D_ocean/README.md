**Implementation of 1D ocean model**


The KC94 model has been implemented as a new module, module_sf_kc1994oml.F, within the surface layer of NU-WRF. It is called through the module_surface_driver.F and the module_sf_ocean_driver.F. Similar to the already present 1-D ocean mixed layer models in NU-WRF, its use is controlled by the namelist keyword “sf_ocean_physics”, which, when set to “3” will activate the KC94 model. Ocean initial conditions are located in the wrfinput file and can be either uniformly defined by giving ocean temperature, salinity, and depth profile values in the namelist (ocean_t, ocean_z, ocean_z) or by directly replacing the ocean fields (OM_TMP, OM_S, OM_DEPTH) in the wrfinput file for a more accurate definition of the 3-D ocean fields. Additionally, values for ocean currents can be given by the user, modifying directly the wrfinput file (OM_U, OM_V) or simply left to 0 by default. Main modifications to the implementation of the KC94 in NU-WRF compared to the original KC94 model (Kantha & Clayson 1994) have been the addition of bathymetry and land-sea mask information, making it suitable not only for open ocean applications but also for coastal and shelf applications in NU-WRF. This information is added by the user by modifying the OM_DEPTH field in the wrfinput (i.e., setting land values = -999). Over these points, a bottom friction option is turned on using a typical logarithmic function to determine the bottom drag coefficient. After each ocean model integration, the SST field is updated through the TSK variable and sent back to the surface layer scheme.

In NU_WRF output file, the ocean variables OM_MLD, OM_TMP and OM_S are updated, respectively, the ocean mixed layer depth, the ocean temperature, and salinity. In addition, several ocean mixing quantities can be output by the model, such as twice the turbulent kinetic energy, the turbulent length scale, and the eddy diffusivity and viscosity (respectively OM_Q2, OM_L, OM_KH, and OM_KM).

Similarly, KC04 will be implemented as a new module (i.e., module_sf_kc2004oml.F) and activated by setting “sf_ocean_physics=4” in the namelist. This more recent scheme involves additional mixing terms related to wave breaking and Langmuir circulation; thus, initial conditions of surface wave fields will be needed. The latter can eventually be taken from the wave variables newly implemented for the wave-based momentum and sea-spray parameterization (i.e., significant wave height, wave period), or if necessary, new wave fields will be made available in either the wrfinput or wrflowinp file.
